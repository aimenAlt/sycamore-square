Five-page static investor website for the Sycamore Square redevelopment study (drawings issue R4.2, October 2026): a 127,634 SF building on 11.72 acres in northeast Memphis, planned as a wedding and event destination with family entertainment and retail. Plain HTML, CSS and vanilla JS with no build step, served by GitHub Pages from `main`; every page is marked noindex and sits behind a one-time password (a light gate; the repository itself is public). The front page (index.html) offers four choices. The overview page (overview.html) includes the R4.2 plans, a layout alternative (halls north, stores south) and a 3D massing section with interactive models of the whole site and the event complex. The legal findings page summarizes flood, zoning and parcel records. The feasibility page compares five development plans for worst, average and best cases, including buying the property at an assumed $3.0M plus fees and closing, rendered from assets/feasibility.json. The Before and during the auction page (auction.html) lists what to check before bidding. The 3D model, renders and downloadable models follow the R4.2 layout, and the site includes AI-generated concept images, each labeled as such. Live site: https://aimenalt.github.io/sycamore-square/
