Three-page static investor website for the Sycamore Square redevelopment study (drawings issue R4.2, October 2026): a 127,634 SF building on 11.72 acres in northeast Memphis, planned as a wedding and event destination with family entertainment and retail. Plain HTML, CSS and vanilla JS with no build step, served by GitHub Pages from `main`; every page is marked noindex. The overview page includes the R4.2 plans, a layout alternative (halls north, stores south) and a 3D massing section with interactive models of the whole site and the event complex. The legal findings page summarizes flood, zoning and parcel records. The feasibility page compares five development plans for worst, realistic and best cases with the purchase price excluded, rendered from assets/feasibility.json. Live site: https://aimenalt.github.io/sycamore-square/
